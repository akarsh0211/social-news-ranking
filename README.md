# social-news-ranking# Social Media News Ranking System

## Overview
This project is a basic full-stack application that ranks social media posts based on engagement metrics such as likes, shares, and comments.

## Features
- Engagement-based ranking algorithm
- Java backend server
- MySQL database integration
- REST-style API
- Simple frontend using HTML & JavaScript

## Ranking Formula
Score = (Likes × 2) + (Shares × 3) + Comments

## Tech Stack
- Java
- MySQL
- HTML
- JavaScript

## How to Run
1. Setup MySQL database using provided SQL.
2. Update database password in Java file.
3. Compile and run backend.
4. Open index.html in browser.
